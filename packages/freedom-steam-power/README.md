# Steam 电源键协调

引用 Freedom 固定提交 `9788014a0293dc26745b000d02854ad88ef73e88` 的按键处理器、输入辅助函数及 systemd 单元，本地补丁只适配会话用户目录，并将恢复 hook 缩减为输入监听重建。

- 游戏模式启动时自动运行；短按仅通过 Gamescope 切换屏幕开关，游戏和音频继续运行，长按约1秒发出 `longpowerpress`，长按释放不会再补发短按。
- 游戏模式退出时，`PartOf` 关系停止处理器并释放 logind 的按键抑制器；桌面继续使用现有电源管理。
- 合盖事件在游戏模式转给 Steam；当前用户没有保护套，物理合盖/开盖尚未验证。
- 真实休眠恢复后，仅向同一用户、同一脚本的进程发送 USR1，重建电源键和合盖输入监听。保留 PID/UID/命令校验。

不替换 systemd-sleep、不引入 fake-suspend、不更改 s2idle 选择，也不关闭电源键唤醒源。详细诊断和MTP的默认开关不受本包影响。

旧版游戏会话已验证长按电源菜单、短按休眠与再次按键唤醒；同boot正常s2idle恢复，监听进程保持PID而输入读取进程重建，无重复休眠。另验证停止处理器会释放按键抑制器并清除输入读取进程。

2026-10-29 同步后，短按行为改为屏幕开关；屏幕请求失败时不退回休眠，部分失败会尝试恢复屏幕，服务退出会恢复由自己关闭的屏幕。`20261025-2` 已安装到平板；亮灭屏和一次 s2idle 恢复验证通过，详见 2026-10-29 的同步记录。
